# Remcy_Tech Website

Single-page site for Remcy_Tech, a graphic design and printing studio in Nairobi, Kenya.

All pages, styles and scripts live in `index.html`. Images such as `logo.png` and `sample_*.jpg` go next to it. If they are missing, the page loads them from https://remcytechltd.netlify.app/.

## Deploy on Netlify
New site → Import from GitHub → pick this repo. Leave the build command empty and set the publish directory to `/`.
